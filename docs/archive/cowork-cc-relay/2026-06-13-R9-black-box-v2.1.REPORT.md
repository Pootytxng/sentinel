## Lane 1 — "None since" measured proof — ✅
**What changed.** A pure `resolutionFor(incident, allIncidents, mark, now)` in
`src/data/blackbox-resolution.ts` that, for an incident whose triage step the user marked **"Did this
help? — yes"**, reports a **measured ABSENCE** from the already-fetched incident timeline:
- none since → **"No {kind} recorded in the {N} days since."** (the doctrine payoff — a fact about the log)
- recurred → **"{kind} happened again on {date}."** (equally honest — recurrence is shown, never hidden)

It **never** says the fix worked / problem solved (an unproven causal claim) — the user draws the
conclusion. Same-kind is matched on the serialized `tag` (the kind discriminator). Recurrence is checked
**before** the elapsed-time gate, so a recurrence surfaces immediately while an *absence* claim waits.

**Refuse-to-show (returns `null` → renders nothing) when:** no `assessment` on the incident (gate OFF /
refuse-to-guess), no "yes" mark, an old untimed mark (can't anchor a "since"), or `< RESOLUTION_MIN_DAYS`
(=1) elapsed **with no recurrence** — no fabricated reassurance.

**Why frontend/pure:** the "yes" marks live in `localStorage` (written by the v2.0 control) and the
timeline comes down from `get_crash_blackbox` — both already on the client, so the math is a pure TS
function. No new OS call, no new IPC, zero outbound. Implicitly gated: it only runs on an incident that
HAS an `assessment`, which the backend populates only when `blackbox_v2_gate()` is ON.

**Verify.** 9 vitest pure-core tests: none-since vs recurred both correct from the real timeline ·
different-kind-after-mark is NOT a recurrence · no "yes" / no assessment (flag OFF) / too-soon / untimed
mark all → nothing · **a banned-words assertion** (`fixed|solved|worked|cured|because|caused|resolved|
guaranteed`) over both output branches · singular/plural day grammar.

**Council.** 🔴 Contrarian: the exact trap this round is the leap from "no X since" to "your fix worked" —
v2.1 **structurally cannot** make it: `resolutionFor` emits only the two factual strings and a test bans
the causal vocabulary. First-Principles: report a measured fact about the log + let the user infer; that
*is* the doctrine ("prove everything"). Expansionist: the local yes/no signal + this absence stat is the
exact seed of v3's fleet "this fix held for N rigs" — built honestly now. Outsider: "happened again on …"
shown just as plainly as the absence is what keeps it from reading like a snake-oil "FIXED!" banner.
Executor: a pure function + a UI swap, no backend, no installer.
