## Lane 1 — "None since" measured proof
When an incident has an `assessment` whose `next_step` the user marked **"Did this help? — yes"** (v2.0
stored that locally), compute from the EXISTING incident timeline whether any NEW incident of the **same
`IncidentKind`** has occurred since that mark. Surface a quiet factual line:
- none since → *"No {kind} recorded in the {N} days since."* (measured absence — the doctrine payoff)
- recurred → *"{kind} happened again on {date}."* (equally honest — don't hide a recurrence)
Pure function over the already-collected incidents + the local did-this-help timestamp. No new OS call, no
fabrication (if there's no "yes" mark or not enough elapsed time, show nothing).

honesty feedback loop staying on the user's machine.
