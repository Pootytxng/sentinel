## What to build
Implement **Black Box v1** exactly per the spec: `docs/superpowers/specs/2026-06-13-black-box-v1.md`.
Read that spec first — it is the source of truth. This file is the execution order + guardrails.

Black Box = a **read-only** crash/freeze evidence reader, folded into **Lab** as an inline
`LabSection` card (NO new rail tab), under the Paramedic Mode umbrella. It reads the crash evidence
Windows already records, overlays Compy's own pre-crash "last vitals" from `sessions.rs`, and presents
each incident in plain English. **v1 makes ZERO causal claims and prescribes ZERO fixes** — it reports
recorded evidence only.

## Build order
1. **`src-tauri/src/blackbox.rs`** (new module) — pure core (`classify_incident`, `correlate_vitals`,
   plain-English phrasing) + unit tests, with a thin Windows collector at the edge (Event Log via
   `Get-WinEvent`/`windows` crate, WER `Report.wer` files, `\Minidump` header bugcheck code, optional
   `Win32_ReliabilityRecords`). Sources + Event IDs are enumerated in the spec (Kernel-Power 41,
   BugCheck 1001, WHEA 17/18/19, Display 4101, App Error 1000, App Hang 1002).
2. **IPC `get_crash_blackbox`** in `lib.rs` `generate_handler!` (mirror `get_diagnostics`). Returns a
   typed `Vec<Incident>` (serde).
3. **Frontend `BlackBox` component** rendered as a `LabSection` in `src/surfaces/Lab.tsx` (collapsible
   card matching Diagnostics). On expand → "Scan for recent crashes" button → `invoke("get_crash_blackbox")`
   → render incidents (plain-English headline · neutral evidence tag · "last vitals" strip when a session
   overlapped, honest "no vitals" when not · "show the receipt" expander with raw IDs/module/codes).
   Update Lab's welcome copy to include the new card in its term/count line.

## HARD LINES (do NOT cross — these are why the feature is safe to ship)
- **Read-only.** No mutation, no new mutation primitive. `actions.rs` UNTOUCHED. No rollback contract
  (it changes nothing).
- **No kernel driver, no game injection.** Every source is user-mode OS logs/files. Anti-cheat-safe —
  never read from or touch a running game process.
- **Zero outbound network.** 100% local. No telemetry in v1 (fleet aggregate is v3, gated separately).
- **No fabricated/unmeasured claims.** No probable-cause, no confidence %, no fix list in v1. If Windows
  recorded nothing, say so. If Compy wasn't monitoring, say "no vitals" — never invent either.
- **Honest about elevation.** Read what's available non-elevated; if a channel/`\Minidump` needs admin
  and you're not elevated, report that source as "skipped," never error out or fake it.
- **Plain language** (Sarah & Caleb bar) — translate event jargon; raw IDs live only behind the receipt
  expander.
- **No always-on background watcher in v1** — on-demand scan only.
