## Historical product-direction material

`RECEIPTS_DOCTRINE.md`, historical PRDs, old `PRODUCT_DIRECTION.md`, archived roadmaps, monetization councils, and pre-rebirth strategy specs are retained only as historical evidence unless a live document explicitly incorporates a bounded fact from them.

If any of those conflict with [PRODUCT_CONSTITUTION.md](PRODUCT_CONSTITUTION.md) on product direction, **the Constitution wins**.

Historical material must not be used to silently restore the former "Care primary / optimization secondary" hierarchy or any other superseded product thesis.
