Real

Resizable BAR / Smart Access Memory

Also searched as: rebar · resizable bar · SAM · smart access memory · above 4g decoding

What it does

Lets the CPU access the GPU's whole VRAM in one mapping instead of small chunks (BIOS + driver).

The honest verdict

Real but title-dependent — a few percent in many games, big in a handful, slightly negative in rare ones. Enable it, measure, and disable per-title only if a game regresses.

How Compy treats it
