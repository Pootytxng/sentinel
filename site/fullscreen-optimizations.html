Disable Fullscreen Optimizations

Also searched as: FSO · fullscreen optimizations

What it does

Turns off Windows' hybrid fullscreen compositor for a specific game's .exe.

The honest verdict

Genuinely changes frame pacing / latency in SOME games and hurts others — it's per-game, so measure it. Not a global win.

How Compy treats it
