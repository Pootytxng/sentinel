Frame Generation (DLSS FG / FSR / AFMF)

Also searched as: frame gen · MFG · AFMF · fluid motion frames · dlss frame generation

What it does

GPU generates extra in-between frames for higher displayed FPS.

The honest verdict

Real smoothness for single-player on a high-Hz display — but it ADDS input latency. Use it in story games, never in competitive shooters. Displayed FPS is not the same as response.
