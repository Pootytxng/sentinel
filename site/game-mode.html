Windows Game Mode

Also searched as: game mode

What it does

Prioritizes the foreground game for CPU/GPU scheduling and holds back background interruptions.

The honest verdict

Modest, low-risk benefit on most rigs; larger on busy/background-heavy systems. Compy can toggle it for you.
