XMP / EXPO memory profile

Also searched as: xmp · expo · docp · ram overclock profile · memory profile

What it does

Enables your RAM's rated speed profile in BIOS (it runs slower out of the box).

The honest verdict

The #1 low-risk BIOS win — real gains in CPU-bound games and 1% lows. If the PC fails to boot, clear CMOS and it's back; run a memory stability test after enabling.

How Compy treats it

Where it genuinely fits a rig, Compy can recommend it — applied with a snapshot first and a one-click rollback after, like every change it makes.
